# Objective Autopilot Expansion Pack

`ObjectiveAutopilot` turns an overall application objective into a durable,
versioned RBox mission contract. It ships finite, continuous, and hybrid
templates and keeps the universal operating constitution fixed while each
application supplies its own authorization, evidence, effect policy, budgets,
and acceptance tests.

Install:

```bash
bash ~/.brainstem/installer/install-expansion-pack.sh objective-autopilot
```

Use `template` to retrieve a starting contract, `validate` to identify only
irreducible configuration gaps, and `compile` to persist a ready mission under
`$RAPP_HOME/autopilot/missions/<mission-id>/mission.json`.
